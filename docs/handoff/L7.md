## Done

- **Live channel** `src/components/streak/live.ts`: `publishStreak`, `useLiveStreak` (§9.6, exact), plus `getLiveStreak` / `subscribeLiveStreak`. The latest published value wins over `initial`; server renders always use `initial`.
- **Streak engine** `src/server/streaks/` (real data, Supabase admin client):
  - `computeStreak(days, today, localHour?)` is pure and replays `daily_activity` on every call. Wave 1: no freezes or repair, a missed day breaks the streak, `freezesAvailable` is always 0. `at_risk` = pending at ≥ 20:00 **or** 00:00–02:59 local. Rows dated after `today` (demo clock moved back) are ignored. Milestones 3/7/14/30/50/100.
  - QR rules (`activity.ts`): an `open` plus a `dwell` on the same article with `value ≥ 20000` (`meta.mode` sheet or missing) or `≥ 8000` (bytes); or `read_original`, `qr_scan`, `recall_answer`. Counts are distinct per article per day, dwells are max-not-sum, so replayed batches never inflate a day.
  - `recordActivity(userId, events, now, tz)` unions the day's stored `events` with the batch (works whether L3 inserts before or after calling it), upserts `daily_activity` and the `streaks` cache, and returns the view with `milestone` set only on the read that crossed it. Edition complete = ≥ 5 stories read and recall answered (a day with no recall questions counts as answered). A batch with no reading signal writes nothing. **It never throws**: any error logs and returns a neutral `new` view (`FIXTURE_STREAK` with `DEMO_FALLBACK=1`).
  - `getStreak` (milestone always null), `getHeatmap` (N days, 5 levels by stories read).
  - `clock.ts`: `localHour(now, tz)`, `nextMorningIso(now, tz)` (next edition day at 07:00 local, as UTC ISO).
- **Routes:** `GET /api/me/streak` → `{ streak, heatmap(84) }`, 401 without a session; `POST /api/demo/clock` → sets/clears the `subah_now` cookie (UTC ISO, `Path=/`, HttpOnly, 30 days), 403 unless `DEMO_MODE=1`, 400 on junk.
- **Streak UI** `src/components/streak/`: `StreakChip({ streak? })` (§9.6; a Morrow ghost `Button` with a dateline "6-DAY STREAK", opens the sheet; fetches `/api/me/streak` when no prop), `StreakSheet` (native modal `<dialog>`, bottom panel < 640 px, right panel above), `StreakPanel` (7-day strip, stats line, milestone line, `ReadingProgress` for today's paper), `StreakStrip` (ink squares + hidden text), `MilestoneToast` (one sonner line per milestone, once). `/me/preview` shows them on fixtures (dev or `DEMO_MODE=1` only).
- Screens: [chip + sheet 390](screens/L7-chip-sheet-390.png), [chip + sheet 1280](screens/L7-chip-sheet-1280.png).
