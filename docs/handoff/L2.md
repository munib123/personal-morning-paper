## Done

- **`@/server/nlp`** (real data): `embedTexts` (local `Supabase/gte-small`, 384-d, normalized; `Xenova/all-MiniLM-L6-v2` if gte-small fails to load; `EMBEDDINGS_PROVIDER=gemini` uses `gemini-embedding-2` at 384 dims) and `runNlp` (raw → embedded: zero-shot labels, leader clusters, importance).
  - First real run on L1's ingest: 1,676 articles embedded and labelled, all with `embed_model = local:Supabase/gte-small` (one vector space).
  - All 67 topics embedded (`scripts/embed-topics.ts`).
  - **Cluster threshold tuned to 0.90** (spec start value 0.82). At 0.82, gte-small chained unrelated stories into 117 clusters of 12; on 1.3 M same-window pairs, 0.80–0.88 is mostly "different story, same topic" and 0.90+ mostly the same story. Re-clustered from stored embeddings: **1,338 clusters, 137 with 2+ sources**, all same-story on inspection (e.g. the Tesla flying Roadster: 12 articles from 10 sources, importance 1.0).
- **Extractive fallback for the whole corpus:** all 1,676 articles are `status = 'fallback'`, `enrich_provider = 'extractive'`, `enriched_at = null`, so **L3's candidate pool has real, rankable stock now**. Summaries are whole sentences (brief = first sentence, std ≈ 60 words, deep ≈ 120), `headline` = title, `key_fact` = first sentence, `recall = null`, `why_it_matters = null`. The next `runEnrich` upgrades them with Gemini.
- **`@/server/ai`:** `callLLM` (ladder SMART → FAST → FALLBACK → fallback, one `retryDelay` wait per 429, breaker, per-day 429 skip until 00:00 PT, per-model RPM pacing, `llm_usage` budget guard via the atomic `increment_llm_usage` RPC, `llm_cache`), `geminiStatus()`, `getLlmCallCount()`. Unit-tested with mocked models only (20 tests).
- Guardrails, Morrow voice checks (headline: no `!`, `?`, emoji; note: no "I", "we", "our AI", `!`, emoji) and the extractive builder are in `src/server/enrich/` (Task 4), ready for `runEnrich`.
