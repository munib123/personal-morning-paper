# L3 Engine (rank + learn + edition + API) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the pure ranking + learning library (fully unit-tested), `buildEdition()` writing real editions to Supabase, the single signal pipeline `processSignals()`, `getProfile()`, `getLearningView()`, every L3 API route, the 7-day simulator with measured metrics, the demo persona seeded with 7 days of real history (by Checkpoint B), and the daily editions job.

**Architecture:** `src/server/rank` is pure TypeScript (no I/O, no clock): Beta-weighted topic affinity + profile-embedding similarity + MMR + seeded Thompson-sampling explore slots → `RankingResult`. `src/server/learn` holds pure priors/rewards/refold, the Supabase load/save of the `UserModel`, `processSignals` (used by `/api/events`, L4's `/r/[articleId]` and `weight_edit`) and `getLearningView`. `src/server/profile` reads/patches `Profile`. `src/server/edition` loads the candidate pool, calls `buildRanking`, writes `editions`/`edition_items`/`interest_snapshots`, and hydrates `Edition` for thin Next.js route handlers.

**Tech Stack:** Next.js 16.4.2 route handlers (async `params`, `after()` from `next/server`; verified via Context7 `/vercel/next.js` canary docs 2026-10-17), @supabase/supabase-js 2.118.0 admin client, zod 4.6.7, vitest 5.0.5 (`vi.mock(import('…'), factory)` verified via Context7 `/vitest-dev/vitest`), tsx 4.23.15, `Float32Array` math.

**Spec:** `docs/ARCHITECTURE.md` §3a (Morrow design system: voice and copy are binding for every string L3 emits), §9 (binding contracts, incl. §9.5 BRAND and §9.7 decisions), §10.4–10.6 (algorithms), §11 (AI budget), §12 (jobs); `design/project/README.md` "Voice and copy" and "Learning"; `docs/PLAN.md` §4–5; research `08-recommendation-learning.md`.

**Estimate:** ≈ 3.25 h of core work (cap 3.75 h); minutes per task are in each heading. L3 renders no UI, so Morrow removes no L3 tasks; it only changes copy (chips, toasts, change summary), the `TimeBudget` tiers and the demo persona, plus one small pure helper for the "You read {n} stories" chip (+3 min, Tasks 4/6). Decisions the spec leaves open:
- **Explore:** `top5` = `RANK_V1_FIXED.exploreExcludeTop` non-muted nodes with highest θ̂ (any level). Eligible nodes: level ≤ `exploreMaxLevel`, not muted, not in top5, with ≥ 1 untaken item whose label equals the node or starts with `node + '.'`. Reserve = next `reserveSize` by the same loop.
- **Rank order:** 1 lead (argmax `s·(1+importance)` with `hasImage` and importance ≥ `leadMinImportance`, else top core item), 2–4 top (next 3 by `s` not in Beyond-your-usual), then core grouped by `sectionOrder` (root Σs desc, items by `s` desc), then Beyond-your-usual in order bigstory, explore, explore, serendipity (unless already lead/top, where slot becomes `lead`/`top` but the reason chip stays). `sectionSlug` = root of top label (`'news'` if no labels).

The lead is always `deep`.
- **Reasons:** slot reasons (explore/serendipity/bigstory, bigstory `{n}` = `c.sourceCount`) weight 1; `topic` (dominant label = argmax conf·θ̂; `Because you follow {name}` if that node or an ancestor is `picked`, else `You read {n} stories on {name} this week` when `readCounts[slug] ≥ 2`, else `More from {name}`), weight = `breakdown.topic`; `similar` when cos ≥ `similarChipMinCos` to an item of `user.engaged` (already last 14 d, max 50; null embeddings skipped), text uses that `EngagedItem.headline`, weight = `breakdown.similarity`; `pinned` weight `weights.pinnedBonus`; sort desc, keep 2. - Toasts (Morrow voice, shown as the one-line note under the `FeedbackBar`): `more`/`taste_more` → `Got it.
