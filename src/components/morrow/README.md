This folder is the Morrow component library (`Icon`, `Button`, `Masthead`, `SectionHeader`, `StoryCard`, `WhyTag`, `FeedbackBar`, `TakeawayBox`, `PullQuote`, `TopicChip`, `Segmented`, `TextField`, `OnboardingStep`, `ReadingProgress`, `EditionCard`), copied from `design/project/components/src/index.tsx` with `'use client'` added and the design-system `window.Morrow` global removed; its styles are `src/styles/morrow/bundle.css` and `src/styles/morrow/tokens.css`. It is owned by L0 and is binding for every lane (ARCHITECTURE §3a): import from `@/components/morrow` and compose these components, never restyle or fork them, and change this folder only through a contract commit of its own, announced in your lane's `docs/handoff/L<n>.md`.
