# Segmented

A row of 2–4 mutually exclusive options, for settings that shape the paper.

- Use for paper length, delivery time, tone (Straight news / Explainers / Mix), and PDF size (A4 / Letter).
- Provide `options` (`value`, `label`, optional `hint`), `value`, `onChange`, and a `label` (renders a legend).
- It is a radio group: arrow keys move between options. More than four options: use TopicChips or a select.
