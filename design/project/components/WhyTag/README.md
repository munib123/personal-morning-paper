# WhyTag

A small pen-blue pill that says, in plain words, why a story is in this reader's paper.

- Every personalized story gets one. Write it from the reader's signals: "Because you follow climate tech", "You read 3 stories on chips this week", "Popular with readers like you".
- Provide the reason as `children` (under 48 characters). Add `onClick` to open a tune panel (follow more / less of this topic).
- Pen blue means "the paper learned this". Do not use it for anything else except links and focus.
