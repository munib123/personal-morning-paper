# Icon

Seventeen line icons drawn on a 24px grid with a 1.75 stroke, inheriting `currentColor`.

- Provide `name`; `size` defaults to 18 (16 inside small controls, 22 standalone). Pass `title` only when the icon stands alone and carries meaning; otherwise it is hidden from screen readers.
- The set matches [Lucide](https://lucide.dev) proportions. In the app, use `lucide-react` with `strokeWidth={1.75}` for anything not listed here.
- `reason` marks personalization (Why-this tags). `plus`/`minus` are More/Less like this. Do not use stars, hearts or thumbs.
- Never decorate headlines or kickers with icons; icons belong to controls and metadata.
