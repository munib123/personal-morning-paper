# SectionHeader

A heavy ink rule with the section name in uppercase Franklin: how the paper divides itself.

- One per section of the edition (World, Technology, Your city, Long read…). Sections come from the reader's interests, ordered by affinity.
- Provide `title`; optional `meta` (story count, why the section exists) and `action`.
- Never color-code sections. They are told apart by name and order, as in print.
