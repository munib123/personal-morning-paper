# TakeawayBox

"Three things to know": the edition boiled down to three sentences, so the reader can name what they learned.

- Sits at the top of the front page beside the lead (and on PDF page 1). Exactly three items; the AI writes each as one complete sentence under 25 words.
- Provide `items` (`text`, optional `kicker`, `href` to the story) and an optional `footnote` stating how it was made.
- Mark the one key phrase per item with `<mark>` (highlight token behind ink). No more than one mark per item.
