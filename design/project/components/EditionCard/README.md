# EditionCard

A miniature front page in the archive: wordmark, date, edition number, lead headline, read progress, Read and PDF.

- The archive is a grid of these, newest first, grouped by week. Today's card is marked "Today" and gets an ink border.
- Provide `date`, `headline` (that day's lead), `edition`, `storyCount`, `readCount`, `readingTime`, `href`, `pdfHref`, `today`.
- Every past edition stays readable and downloadable exactly as it was published; never regenerate an old paper.
